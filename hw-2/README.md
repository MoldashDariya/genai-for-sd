# HW 2 — Neural networks from scratch

Practical tasks of *Module 1: Theory of Large Language Models (LLMs)*.
Each task is solved in **Java** and in **Python** without ML libraries:
forward pass, backpropagation, Mean Squared Error loss, stochastic gradient descent.
Training and test data are generated by the code itself.

| Task | Java | Python |
|---|---|---|
| **Point Inside a Circle** — is the point (x, y) inside the circle with center (0, 0) and radius 5? Output: 1 — inside, 0 — outside | [`java/point-inside-circle`](java/point-inside-circle) · 2 → 16 tanh → 1 sigmoid · **95 / 100** | [`python/point-inside-circle`](python/point-inside-circle) · 2 → 12 tanh → 1 sigmoid · **97 / 100** |
| **Maximum of Three Numbers (-1…1)** — max(x1, x2, x3) for numbers in [-1, 1] | [`java/max-of-three-numbers`](java/max-of-three-numbers) · 3 → 32 ReLU → 1 tanh · **98 / 100** | [`python/max-of-three-numbers`](python/max-of-three-numbers) · 3 → 24 ReLU → 1 tanh · **97 / 100** |

Scores are from the Autocode automated check.

## Key ideas

- **Circle:** the classes are balanced when generating data (half of the points inside, half outside);
  coordinates are scaled to about [-1, 1]; a sigmoid output gives the probability of "inside".
- **Maximum:** ReLU hidden neurons describe the piecewise linear function max well
  (max(a, b) = b + relu(a − b)); a tanh output keeps the answer in [-1, 1].
  Data generation adds samples with a uniformly distributed maximum and with nearly equal numbers —
  the regions plain uniform sampling barely covers.
